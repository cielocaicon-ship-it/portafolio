# Portafolio — Cielo Yenied Caicedo Contreras

Portafolio web de Ingeniería Multimedia (Universidad Simón Bolívar, sede Cúcuta).

**Ver en línea:** https://cielocaicon-ship-it.github.io/portafolio/

## Páginas

| Página | Qué tiene |
|---|---|
| `index.html` | Inicio: presentación, sobre mí, habilidades y proyectos |
| `blog.html` | Trabajos: diseño, posproducción y videojuegos |
| `juegos.html` | Videojuegos de la saga Petunia, récords e historial de partidos |
| `contacto.html` | Formulario de contacto |
| `futbol.html`, `pingpong.html`, `noche-de-espantos.html`, `condor-de-los-andes.html`, `estanco-nucita.html` | Cada juego a pantalla completa con botón para volver |

## Videojuegos (carpeta `juegos/`)

- **PetuGol** — futbolito arcade 6 contra 6 contra Petunia.
- **PetuPong** — ping-pong contra Petunia o para 2 jugadores.
- **Noche de Espantos** — supervivencia 3D con mitos y leyendas colombianos.
- **Cóndor de los Andes** — guerra aérea 3D por la historia de Colombia.
- **Estanco Nucita** — Pamela atiende su estanco con la perrita Nucita.

## JavaScript del portafolio (carpeta `js/`)

- `tema.js` — alternador de modo oscuro / claro (se recuerda con LocalStorage).
- `marcadores.js` — historial de partidos y récords (High Scores) en LocalStorage, en formato JSON, con botón para reiniciar estadísticas.
- `arcade.js` — animaciones de la página de videojuegos.
- `jugador.js` — pantalla de juego: pasa el teclado al juego.
- `pestanas.js`, `visor.js`, `pila.js`, `contador.js`, `animaciones.js` — pestañas de Trabajos, visor de imágenes, efecto del inicio, contador del formulario y animaciones al bajar.

Hecho con HTML5, CSS3, JavaScript, Canvas y Bootstrap. Publicado con GitHub Pages.
